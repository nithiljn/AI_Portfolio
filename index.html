KadalValzhi: AI Fisherman Guidance System

Real-time multi-agent guidance platform for weather, pricing, fuel, and voyage safety

A real-time AI guidance system for fishermen that handles weather risk analysis, fish market price forecasts, fuel cost estimates, and voyage profitability using an autonomous LangGraph multi-agent architecture.

  • Multi-Agent Architecture: Developed specialized Weather, Financial, Guide, and LLM-as-Judge agents, tracking evaluation metrics with LangSmith.
  • RAG Pipeline with ChromaDB: Built vector store retrieval using cosine similarity search on official fishery documents for context-aware responses.
  • Predictive Vision and Forecasting: Trained an LSTM time-series forecasting model and connected PaddleOCR with a Vision-Language Model (VLM) for fish image data extraction and valuation.
  • Safe Fallback Loop: Integrated OpenWeather API with a 3-attempt fallback loop across multiple weather services. If all requests fail, the system explicitly warns fishermen instead of serving unverified data to protect lives at sea.
  • Performance and Reliability: Applied the Singleton pattern and LRU caching, logging daily fishing profit and loss into PostgreSQL for historical AI guidance models.
