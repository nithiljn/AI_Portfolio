KadalVazhi (கடல் வழி): Maritime Microservices & AI Platform

Enterprise polyglot microservices platform for deep-sea fleet voyages, emergency crew exchange, and direct dockside catch pre-orders

An enterprise-grade, polyglot microservices ecosystem tailored for deep-sea fishing communities and fleet owners. Features an offline-first voyage engine, Apache Kafka event streaming, zero-middlemen dockside catch pre-booking, emergency crew replacement, and a Tamil/Malayalam voice AI advisory engine.

  • Polyglot Microservices & Event Streaming: Core transactional services engineered in Java 25 and Spring Boot (nn-home-service, fleet-service, crew-exchange-service, marketplace-service) routed via Spring Cloud Gateway, using Apache Kafka for asynchronous event-driven workflows (trip events, catch declarations, emergency alerts).
  • Offline-First Zero-Connectivity Sync: Solved 5-to-10 nautical mile offshore dead zones with local SQLite storage on mobile clients, executing idempotent background synchronization to PostgreSQL once vessels regain coastal 4G connectivity.
  • Direct-From-Sea Pre-Order Marketplace: Built a dockside catch pre-order system enabling captains to declare catches while at sea, linking vessel arrival ETAs at major fish landing centers (Kasimedu, Tuticorin, Rameswaram, Munambam) directly to buyers and eliminating exploitative middlemen.
  • Voyage Ledger & Subsidized Fuel Quota: Engine supporting all vessel classes (from 1-day country crafts and FRP fiber boats to 15-day mechanized trawlers), tracking government diesel/kerosene quota balances, ice supplies, crew rosters, and trip P&L.
  • Emergency Crew Exchange & AI Voice Advisory: Real-time dispatch board for urgent port crew hiring, paired with a Python FastAPI AI Voice Engine using Whisper STT (Tamil/Malayalam) and LLM reasoning for marine safety alerts and annual fishing ban compliance.
  • AWS Cloud & Automated Jenkins CI/CD: Containerized microservices orchestrated on AWS EKS Kubernetes with Application Load Balancers, Multi-AZ RDS PostgreSQL (JSONB), and automated canary deployments via Jenkins pipelines.
